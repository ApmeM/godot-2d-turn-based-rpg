# Utils

Общие расширения, сигналы и загрузка сцен, которыми пользуются остальные компоненты.

- `CommonSignals` содержит строковые имена стандартных Godot-сигналов.
- `NodeExt.FreeChildren()` и `RemoveChildren()` упрощают очистку дерева.
- `ObjectExt.ToMySignal(...)` преобразует Godot-сигналы в асинхронный `Task` с перегрузками для 0–4 значений.
- `Instantiator.LoadLoot(name)` и `CreateLoot(name)` загружают предметы по соглашению `res://Presentation/loots/{name}/{name}.tscn`.

Это runtime-библиотека без собственной сцены. Перед использованием загрузчик инициализируйте в проекте с доступной структурой loot-сцен.
