# TurnBase.Tests

## Краткое описание

Это набор автоматических тестов для проверки правил KaNoBu и поведения AI-игроков. Папка предназначена для регрессионной проверки логики боя, правил ходов, продвижения фигур и поведения ботов.

## Какого типа классы и файлы она должна содержать

Эта папка должна содержать:
- NUnit-тесты для набора игровых сценариев;
- проверки правил боя и продвижения фигур;
- проверки логики ходов и валидации;
- проверки поведения ботов Easy и Medium;
- вспомогательные внутренние классы для тестовых сценариев и фейковых фигур.

Тут не должно быть игровой логики, только проверка корректности поведения уже существующего кода.

## Роль и устройство

`TurnBase.Tests` — это проект регрессионных тестов, который проверяет, что механика KaNoBu работает корректно после изменений в правилах, фигурах или AI.

Ключевые области проверки:
- `KaNoBuBattleTests` — проверяет логику боев между типами фигур, включая флаги, мины и универсальную фигуру;
- `KaNoBuMoveTests` — проверяет, какие фигуры могут двигаться и какие ходы являются допустимыми;
- `KaNoBuRulesTests` — проверяет распределение бонусов победы, повторное продвижение в универсальный тип, лимиты ходов и порядок применения нескольких ходов;
- `KaNoBuPlayerEasyTests` и `KaNoBuPlayerMediumTests` — проверяют поведение ботов и корректность ограничения ходов в раунде.

Тесты служат проверяемым описанием ожидаемого поведения. При изменении правил KaNoBu нужно обновить соответствующие тесты и, если изменился смысл компонента, описания в `Figures`, `Rules`, `Players` и `Models`.

Поскольку это проект проверки, он должен оставаться максимально целенаправленным: каждый тест должен описывать конкретный сценарий и ожидаемый результат, без лишнего шума и без тестирования внутренних деталей реализации, если это не требуется.
