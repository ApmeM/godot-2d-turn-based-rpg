# Theme

Общая тема пользовательского интерфейса и шрифты проекта.

Назначайте `UITheme.tres` свойству Theme у Control-узлов или сцен. `Buttons.png` содержит графику состояний кнопок, а каталог `Fonts` — доступные шрифты.

Отдельно подключать скрипт или регистрировать editor plugin не нужно. Компоненты UI из соседних каталогов могут ссылаться на эти ресурсы напрямую.
