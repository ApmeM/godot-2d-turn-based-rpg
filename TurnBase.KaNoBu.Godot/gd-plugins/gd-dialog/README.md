# Dialog

Диалоговое окно с печатью текста, двумя позициями персонажей и возможностью пропустить анимацию.

Добавьте `Dialog.tscn` в UI. Метод `Show(string text, bool left, Texture image)` запускает реплику; `left` выбирает сторону персонажа, а `image` задает его портрет. `ForceFinish()` немедленно показывает оставшийся текст. Скорость задается свойством `Speed`.

Клик мышью, Space и Escape ускоряют или завершают текущую реплику. Сцена использует `gd-theme/UITheme.tres` и изображения `Background.png`, `talk1.png`, `talk2.png`.
