# LevelSelector

Кнопка запуска уровня и связывания с кнопкой следующего уровня.

Добавьте `LevelButton.tscn`, задайте `GameToStart` как PackedScene уровня и при необходимости укажите `NextLevelButton`. Свойство `LevelName` вычисляется из сцены, а `GetNextLevel()` возвращает следующую доступную кнопку.

Компонент использует группу `LevelButton` и рассчитан на сцены уровней, которые можно инстанцировать через `PackedScene`.
