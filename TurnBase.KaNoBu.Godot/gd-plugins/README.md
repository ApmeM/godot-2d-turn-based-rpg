# Общие компоненты Godot

Эта папка содержит переиспользуемые runtime-компоненты для Godot Mono и C#. Они подключаются как обычные ресурсы проекта: нужную `.tscn` добавляют в дерево сцены, настраивают экспортируемые свойства в Inspector и вызывают публичные методы из кода. Это не набор Godot EditorPlugin: включать его через `Project Settings -> Plugins` не требуется.

## Быстрый принцип работы

1. Добавьте нужную сцену из этой папки в UI или игровую сцену.
2. Проверьте пути к связанным ресурсам и задайте `[Export]`-поля.
3. Получите узел через `$NodePath` или `GetNode<T>()` и используйте его публичный API.
4. Для асинхронных UI-операций дождитесь возвращаемого `Task`; узел должен находиться в `SceneTree`.

Компоненты рассчитаны на Godot 3.x Mono API. В проекте используются C#-сцены, `PackedScene.Instance`, Godot-группы и `user://` для локальных данных. Некоторые классы имеют `[Tool]`, поэтому часть свойств обновляется прямо в редакторе; это не делает компонент EditorPlugin.

## Связи между компонентами

UI-слои используют общую тему и шрифт. Всплывающие окна могут выводить текст через typewriter-компонент, а инвентарь использует popup-ресурсы и сцены лута. Достижения поддерживают локальное хранилище и Android-адаптер Google Play Games Services. Плавающий текст, таймеры, индикаторы здоровья, миникарта, камера и touch-управление можно подключать независимо.

Для инвентаря сохраняйте соглашение проекта: сцены лута находятся в `res://Presentation/loots/{name}/{name}.tscn`, а их идентификаторы совпадают с именами, передаваемыми в `LootDefinition` и `Instantiator`. Элементы миникарты должны состоять в группе `MinimapElement`; размер карты и центр задаются явно.

Android-интеграцию Google Play нужно добавлять только в Android-сборку и предварительно настроить соответствующий Godot Android plugin. Без него используйте локальный репозиторий достижений. Для достижений также проверьте пути к JSON и ресурсам относительно `res://gd-plugins/gd-achievements/`.

Каждая непосредственная подпапка содержит собственный README с подробностями API и примером применения. Вложенные каталоги `resources`, `data` и `Fonts` являются ресурсами конкретного компонента, а не отдельными runtime-модулями.
