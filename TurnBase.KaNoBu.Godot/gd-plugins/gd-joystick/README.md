# Joystick

Экранный touch-джойстик из четырех направлений.

Добавьте `Joystick.tscn` в мобильный UI. Сцена содержит `TouchScreenButton` и использует действия ввода проекта, поэтому названия input actions должны совпадать с теми, которые читает игровое управление. `cross.png` является графикой центрального элемента.
