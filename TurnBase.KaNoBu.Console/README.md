# TurnBase.KaNoBu.Console

## Краткое описание

Это консольный запускатель и демонстрационный клиент для KaNoBu. Папка предназначена для запуска партии в терминале, где игроки могут инициализировать поле, задавать ходы вручную или использовать готовых AI-ботов.

## Какого типа классы и файлы она должна содержать

Эта папка должна содержать:
- точку входа приложения (`Program.cs`);
- консольного игрока, реализующего `IPlayer<...>` для KaNoBu;
- любой вспомогательный код для чтения ввода пользователя, отображения поля и выбора хода;
- короткие примеры запуска игры с готовыми правилами и ботами.

Папка служит демонстрационной и отладочной оболочкой, а не ядром игровой логики.

## Роль и устройство

`TurnBase.KaNoBu.Console` предоставляет простой способ запустить KaNoBu в командной строке. Это полезно для локальной проверки правил, ручного ввода ходов и воспроизведения игр без графического интерфейса.

Основные элементы:
- `Program` создаёт `KaNoBuRules(8)`, собирает игру через `Game<...>`, добавляет несколько `KaNoBuPlayerEasy` и подключает `ReadableLogger` с `ConsoleLogger` для вывода событий;
- `KaNoBuPlayerConsole` реализует `IPlayer` и позволяет человеку играть через текстовый ввод: ввод имени, расстановка фигур, выбор хода в формате вроде `A0-A1`.

В этой папке не должно быть игровой бизнес-логики, кроме UI/IO-слоя для консоли. Новые типы ручного игрока, формы ввода и режимы запуска остаются здесь, а правила и механика KaNoBu продолжают жить в `TurnBase.KaNoBu` и `TurnBase`.

Важно понимать, что это проект-пример и средство проверки. Он должен оставаться минималистичным и прозрачным, чтобы отличать пользовательский интерфейс от игровых правил.
