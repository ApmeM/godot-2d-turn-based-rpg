# HP

Визуальный индикатор здоровья на основе кадров спрайта `HP.png`.

Добавьте `HP.tscn` как дочерний узел персонажа и задайте `MaxHP` и `CurrentHP`:

```csharp
var hp = GetNode<HP>("HP");
hp.MaxHP = 8;
hp.CurrentHP = 6;
```

Спрайт содержит восемь кадров. Узел скрывается при полном здоровье и при `MaxHP == 0`. `[Tool]` позволяет видеть изменения в редакторе.
